# KAGE Barber

[**Acessar o site ↗**](https://httpste.github.io/kage-barber/)

Criei este site para uma pessoa que era muito especial para mim. Coloquei carinho em cada detalhe, embora hoje eu ache que ela não merecia nem uma `<div>` vazia.

O tema é inspirado em Nanatsu no Taizai, com referências aos sete pecados capitais e à estética dos dark animes. O preto, o vermelho e a navegação por capítulos fazem parte dessa proposta.

Quis trazer essa atmosfera para uma barbearia com personalidade, dando destaque aos cortes, ao estilo e à identidade visual.

O projeto usa HTML, CSS e JavaScript, com site responsivo. Nesta versão demonstrativa, a marca, os nomes, as imagens e os contatos são fictícios.

Feito por Stephany.
